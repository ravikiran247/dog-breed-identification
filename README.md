# Dog Breed Identification using Transfer Learning

## Project Overview
This project uses Transfer Learning with VGG19 to classify 20 dog breeds from images. The model is trained using TensorFlow and deployed using Flask and Render.

## Technologies Used
- Python
- TensorFlow / Keras
- VGG19 (Transfer Learning)
- Flask
- Gunicorn
- Render (Cloud Deployment)

## Dataset
Dog Breed Identification Dataset (20 classes)

## Model Architecture
- Pre-trained VGG19 (ImageNet weights)
- Flatten Layer
- Dense Layer
- Softmax Output (20 classes)

## Deployment
Live App:  
https://dog-breed-identification-1.onrender.com

## How It Works
1. User uploads image
2. Image is preprocessed
3. Model predicts breed
4. Result displayed on webpage
